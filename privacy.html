Google OAuth and API scopes

Google OAuth и разрешения API

The app connects to Google with OAuth and uses the YouTube Data API solely to manage content on the owner’s own YouTube channels. It requests these scopes:

Приложение подключается к Google через OAuth и использует YouTube Data API только для работы с контентом на собственных каналах владельца. Запрашиваются следующие разрешения:

  • https://www.googleapis.com/auth/youtube.upload — upload videos and set thumbnails (videos.insert, thumbnails.set).загрузка видео и установка обложек (videos.insert, thumbnails.set).

What data is used

Какие данные используются

With the owner’s consent, the app uses OAuth tokens and YouTube channel identifiers needed to upload and update videos on those channels. Video files, titles, descriptions, thumbnails and captions are submitted by the owner for publication. The Google account password is never received by the app.

С согласия владельца приложение использует OAuth-токены и идентификаторы каналов YouTube, необходимые для загрузки и обновления видео на этих каналах. Файлы видео, названия, описания, обложки и субтитры передаёт сам владелец для публикации. Пароль аккаунта Google приложению не передаётся.

Neura Uploader does not collect personal data from other users, viewers, or members of the public. It does not read comments, subscriptions, or private viewer information.

Neura Uploader не собирает персональные данные других пользователей, зрителей или посетителей. Приложение не читает комментарии, подписки и личные данные зрителей.

Хранение, передача и продажа

Neura Uploader stores OAuth tokens to authenticate requests to YouTube. Tokens and YouTube data obtained through the API are not shared with third parties, not sold, and not used for advertising or to train general-purpose AI models.

Neura Uploader хранит OAuth-токены для авторизации запросов к YouTube. Токены и данные YouTube, полученные через API, не передаются третьим лицам, не продаются и не используются для рекламы или обучения общих моделей ИИ.

Revoking access and data requests

Отзыв доступа и запросы по данным

You can revoke Neura Uploader’s access at any time on the Google Account permissions page: myaccount.google.com/permissions → select the app → “Remove access”. Revoking access immediately stops all further API calls: the stored token stops working. To also delete it from the server, see “Data deletion” below.

Отозвать доступ Neura Uploader можно в любой момент на странице разрешений аккаунта Google: myaccount.google.com/permissions → выбрать приложение → «Удалить доступ». После отзыва обращения к API сразу прекращаются: сохранённый токен перестаёт действовать. Чтобы удалить его и с сервера, см. «Удаление данных» ниже.

Data deletion. To delete stored OAuth tokens and related records (upload log, quota counters), send a request to neuratrade.official@gmail.com. We confirm the request and delete the data within 30 days of receiving it. Videos already published on YouTube are managed in YouTube Studio and can be deleted there by the channel owner.

Удаление данных. Чтобы удалить сохранённые OAuth-токены и связанные записи (журнал загрузок, счётчики квоты), напишите на neuratrade.official@gmail.com. Мы подтвердим запрос и удалим данные в течение 30 дней с момента его получения. Видео, уже опубликованные на YouTube, управляются в YouTube Studio, и владелец канала может удалить их там.

Retention. Tokens are kept only for operating the app. The upload log contains technical records only (video file checksum, video ID, time, quota used) and no viewer data.

Хранение. Токены хранятся только для работы приложения. Журнал загрузок содержит только технические записи (контрольная сумма файла, ID видео, время, израсходованная квота) и не содержит данных зрителей.
